# 온보딩 절차

| 단계 | 담당 | 내용 |
|---|---|---|
| ① 신청·목록 제출 | 협력사 | RTU 목록과 담당자 정보 제출 |
| ② 매핑 등록 | 해줌 | rtu_id 등록 |
| ③ 자격증명 수령 | 협력사 | stg 접속정보·자격증명·가늠 안내 수령 |
| ④ TLS 연결 확인 | 협력사 | MQTT 5.0 + TLS 1.3 접속 |
| ⑤ 로컬 자기시험 | 협력사 | [가늠](../tools/)으로 실제 발행 바이트 전수 검증 |
| ⑥ stg 발행 | 협력사 | telemetry·info 발행 시작 |
| ⑦ 수신·규격 확인 | 해줌 | 스키마·주기·rtu_id 매핑·시각 확인 |
| ⑧ 통과 통보 | 해줌 | 통과 시 서면 통보 후 운영 전환 일정 협의 |
