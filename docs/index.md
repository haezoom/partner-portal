# 해줌 협력사 포털

해줌과 MQTT 표준으로 연동하는 RTU·EMS 협력사를 위한 문서와 도구를 모았습니다.

## 연동 흐름

| 단계 | 할 일 | 안내 |
|---|---|---|
| 1. 표준 확인 | 자원 종류(태양광·ESS)에 맞는 표준 문서를 읽습니다 | [표준 문서](standards/) |
| 2. 로컬 자기시험 | 가늠(ganeum)으로 내가 보낼 메시지를 broker 접속 전에 검증합니다 | [자기검증 도구](tools/) |
| 3. 온보딩 신청 | RTU 목록과 담당자 정보를 제출합니다 | [온보딩](onboarding/) |
| 4. 연동 검증·전환 | 해줌과 수신 확인 후 운영으로 전환합니다 | [온보딩](onboarding/) |
